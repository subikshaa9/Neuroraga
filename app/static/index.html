Processing recipe: each channel is processed independently. The code removes that channel's DC mean and linear trend, then applies a 4th-order zero-phase 0.5–40 Hz Butterworth response at the timestamp-verified rate. The 40 Hz low-pass attenuates 50 Hz, so no extra 50 Hz notch is applied. Synthetic-tone response validation is reported below.
Outputs: the “filtered” CSV keeps original raw columns and every sample, then adds filtered columns and per-channel artifact flags. The “clean” CSV keeps all timestamps but blanks only flagged channel values; it does not delete good samples from other channels. Review flags and protocol annotations. Neither filtering nor automatic flags prove a change was music-caused or guarantee artifact-free EEG.
Physical units: the local Capsule SDK binding documents raw values as floats, but does not provide a volts or microvolts conversion. No unit conversion is guessed; the report marks unit status unconfirmed and says the file is not ready for segmentation.
